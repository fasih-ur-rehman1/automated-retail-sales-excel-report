# Automated Retail Sales Excel Report

A Python-based data analysis and Excel automation project that transforms raw retail transaction data into a clean, structured, and presentation-ready Excel business report.

The project combines data profiling, cleaning, exploratory analysis, business metrics, Excel reporting, table formatting, and automated chart generation into a single workflow.

---

## 📌 Project Overview

Raw retail transaction data is often difficult to analyze directly because it may contain:

- Duplicate transactions
- Cancelled orders
- Negative quantities
- Invalid prices
- Missing customer information
- Missing product descriptions
- Inconsistent or unusable records

This project processes the raw dataset, applies business-driven cleaning rules, performs analysis, and automatically generates a formatted Excel report containing summary metrics, analytical tables, and visualizations.

---

## 🎯 Project Objectives

- Profile the quality and structure of raw retail data
- Identify and handle problematic records
- Perform exploratory data analysis (EDA)
- Generate useful business metrics
- Analyze sales trends over time
- Identify top-performing products
- Analyze sales performance by country
- Automatically generate a professional Excel report
- Automate Excel tables, formatting, and charts
